Program that outputs a table of values ​​for the function (x+1)^2 / (x-1)^(1/2), consisting of the argument x values ​​and the function values.

The values ​​of the argument and the function are output with two decimal places, separated by a single tab character.
The program takes as input the starting value, the ending value, and the step size for the function's argument, x. The starting value, ending value, and step size are real numbers.
If it is not possible to calculate the function's value, the corresponding row in the table should display the value of $x$ followed by the message "not defined".
The program must handle input errors; if the user enters text instead of a number, it should display the message "input-output error" and terminate the program.
